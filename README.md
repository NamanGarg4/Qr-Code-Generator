This is a small project where I created a QR Code Generator using only HTML and CSS (with a bit of inline JavaScript). The goal was to keep it simple, fast, and free from the clutter you usually find on QR code websites. You just type any text or URL, hit generate, and the QR code appears instantly.

Features
- Instantly generates QR codes for any text or URL
- Clean and simple interface
- You can press Enter or click Generate to create a QR code

Built With
- HTML for structure
- CSS for styling

How to Run
1. Download or clone this repository
2. Open the file index.html in your browser
3. Start generating QR codes

Future Improvements
- Option to download the QR code
- Add color customization
- Export in formats like SVG or PDF
- Add dark and light mode
